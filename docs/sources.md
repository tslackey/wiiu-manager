# Authoritative sources

Re-check these the day you touch the console. Prefer them over any gist, YouTube video, or this repo’s prose.

## Must use

- [Wii U Hacks Guide](https://wiiu.hacks.guide/) — stock to Aroma
- [Aroma packages](https://aroma.foryour.cafe/) — Base Aroma, payloads, extra plugins
- [Aroma GitHub](https://github.com/wiiu-env/Aroma)
- [EnvironmentLoader](https://github.com/wiiu-env/EnvironmentLoader)
- [PayloadLoader installer](https://github.com/wiiu-env/PayloadLoaderInstaller)

## Recommended extras (already in the `recommended` profile)

- SaveMii ProcessMod: https://github.com/w3irDv/savemii
- Homebrew App Store: https://github.com/fortheusers/hb-appstore
- Bloopair / FTPiiU / SDCafiine / Screenshot / SwipSwapMe: via aroma.foryour.cafe package IDs in `config/packages.json`

## Later, not day one

- vWii: linked from [Finalizing Setup](https://wiiu.hacks.guide/aroma/finalizing-setup.html)
- Pretendo / Inkay: https://pretendo.network/ and aroma package `inkay`
- Nintendont: project docs only after vWii is done, dumps of discs you own
- ISFShax / de_Fuse: recovery tooling, not a first install

## Explicitly do not start from

- GBATemp threads that lead with Haxchi/CBHC for a stock 5.5.x box
- “Wii U custom firmware 2017” videos
- Random mirrors of Aroma zips
- Title-key sites and backup ROM storefronts

## Guide hashes

The Hacks Guide publishes SHA256 values on [hashes.html](https://wiiu.hacks.guide/hashes.html). Those listings lag Aroma betas (they still mentioned Beta-25 while aroma.foryour.cafe was serving Beta-27). Trust aroma.foryour.cafe + GitHub releases for current bits; use the hash page when you downloaded a *guide-hosted* zip.
